# Freelancer Website

## Overview

This project is a Freelancer Website that connects clients with freelancers offering various services. Users can register as clients or freelancers, post gigs, request jobs, and leave reviews.

## Features

- **User Management**: Admins, freelancers, and clients with roles and permissions.
- **Gig Posting**: Freelancers can post detailed service offerings.
- **Job Requests**: Clients can hire freelancers for gigs.
- **Reviews**: Clients can review freelancers after job completion.
- **Admin Logs**: Track admin activities for transparency.

## Database Structure

The database consists of the following tables:

- **Users**: Stores user details and roles.
- **Categories**: Contains gig categories.
- **Gigs**: Lists freelancer services.
- **Job Requests**: Manages client requests to freelancers.
- **Reviews**: Client reviews of freelancers.
- **Admin Logs**: Logs admin actions.
- **Client Gigs**: Links clients to gigs.

## How to Run

1. Clone the repository.
2. Set up the database using the provided SQL scripts.
3. Run the application server.
4. Access the website through your browser.

## Technologies Used

- **Backend**: SQL, with table structures for users, gigs, job requests, and more.
- **Frontend**: HTML/CSS for basic styling.
- **Version Control**: Git for source code management.
